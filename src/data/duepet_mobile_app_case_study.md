# Duepet Mobile App – Case Study

## Overview
Duepet is a mobile application designed to help pet owners manage and track their pet-related activities, services, and needs. The platform aims to streamline interactions between pet owners and service providers, offering a centralized digital experience.

**Project URL:** https://duepet.com/

## Context & Objectives
The primary objective of the Duepet project was to design and deliver a scalable, reliable backend system capable of supporting a mobile-first experience, while ensuring seamless collaboration with a distributed frontend team.

Key goals:
- Build a robust and scalable backend architecture
- Enable real-time and reliable data synchronization
- Support rapid feature iteration driven by client needs
- Ensure maintainability and operational efficiency

## Role & Responsibilities
- Designed and developed the server-side architecture
- Led and coordinated the frontend development team
- Delivered custom, client-oriented features on demand
- Applied best practices in database design and system operations
- Collaborated within a partnership framework with a UK-based web agency
